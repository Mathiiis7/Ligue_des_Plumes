🏆 Générateur de trophées 5 paliers

Le trophée doré actuel est chargé automatiquement. Dépose une autre image pour l'utiliser comme source. La palette de droite définit les 5 tiers (bronze / argent / or / diamant / prismatique) — édite-la à la volée.

Palette 6 couleurs
Zone socle préservée
Zone protégée fixée à 70% de la hauteur (bas) + couleur du socle fixée à #3d211c. Les pixels de cette teinte dans le bas de l'image sont préservés sur les 6 tiers, l'oiseau au-dessus est toujours retinté.
Comment ça marche ?
Chaque tier définit un gradient map à 3 stops (ombre / mid-tone / reflet) auto-dérivé de sa couleur : le mid-tone est la couleur choisie, l'ombre est une version très sombre et légèrement moins saturée (profondeur), le reflet est une version très claire tirant vers le blanc (brillance métallique).

Pour chaque pixel du PNG source, la luminance décide où l'on tombe dans ce gradient : les zones sombres du trophée prennent l'ombre, les zones moyennes prennent la couleur choisie, les reflets prennent la couleur claire. Résultat : rendu métallique cohérent au lieu d'un teintage plat — ombres réellement sombres, reflets vraiment brillants.

Les pixels très sombres et neutres (base, socle, contours noirs) sont préservés tels quels pour garder le contraste avec la coupe.

Prismatique : le gradient map est recalculé par pixel avec un hue variant en diagonale (rose → violet → cyan → vert → jaune) pour un rendu iridescent.

Une fois téléchargés, place les 5 PNGs dans assets/trophies/families/{nom}/ avec les noms bronze.png / argent.png / or.png / diamant.png / violet.png, puis ajoute imgDir:'assets/trophies/families/{nom}' dans la config du trophée dans app.js.
