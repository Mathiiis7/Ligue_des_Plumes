🏆 Générateur de trophées 6 paliers

Dépose la version dorée d'un trophée, ça te sort les 5 autres couleurs (bronze / argent / diamant / améthyste / émeraude) prêts à télécharger.

Palette 6 couleurs
Comment ça marche ?
L'image dorée est décomposée par pixel. Les pixels colorés (le corps de la coupe) sont décalés en teinte HSL vers la couleur cible de chaque palier. Les pixels neutres (base marron foncée, plaque, contours, ombres) sont préservés — leur saturation nulle les rend insensibles au shift de teinte.

Résultat : la coupe change de couleur mais le socle et les détails restent identiques à la version originale. Compatible avec les PNG stylisés type Canva.

Une fois téléchargés, place les 6 PNGs dans assets/trophies/families/{nom}/ avec les noms bronze.png / argent.png / or.png / diamant.png / violet.png / emeraude.png, puis ajoute imgDir:'assets/trophies/families/{nom}' dans la config du trophée dans app.js.
